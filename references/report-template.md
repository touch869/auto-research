# 简评规范与周报模板

report 模式 [4] 简评、[5] 成报 阶段的写作规范。

## 简评( brief )写作规范

每条筛选保留的条目,强模型写 **3-5 句简评**,固定三段式:

1. **做了啥**( 1 句 ):这项工作/发布是什么,核心做了什么。
2. **为啥重要**( 1-2 句 ):解决了什么问题 / 突破了什么 / 对领域意味着什么。
3. **适合谁**( 1 句 ):目标读者( 正在搭 X 的人 / 关注 Y 的人 / 入门者 )。

要求:
- 基于条目的 `summary_raw` 写,**不许编造**数据/结论。
- 中性陈述,不吹不黑;有明确缺陷可点出。
- 写进条目的 `brief` 字段。

**简评质量自检**:能不能让一个读者 10 秒内判断"这篇我要不要点开看"?不能就重写。

## 周报成报( render_report.py )

简评写完后,构造 `briefs.json` 喂给渲染脚本:
```bash
python scripts/render_report.py tmp/briefs.json --topic "<主题>" --date <YYYY-MM-DD> --out output/<主题>-<日期>.md
```

`briefs.json` 结构:
```json
{
  "overview": "本期概览一段话( 讲清这期大势 )",
  "trends": ["趋势1", "趋势2", "趋势3"],
  "items": [
    { "...原始字段...", "brief": "三段式简评", "tag": "paper" }
  ]
}
```

`overview` 和 `trends` 由强模型在写完所有简评后,综合归纳得出( 不是简单拼接 )。

## 输出文件命名
`output/<主题英文slug>-<YYYY-MM-DD>.md`,如 `world-model-agent-2026-08-12.md`。
